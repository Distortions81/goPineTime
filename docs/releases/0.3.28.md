# goPine 0.3.28 candidate

This checkpoint retains the 0.3.27 InfiniLink Device Information fix, two saved
paired devices and three live OTA connections. It adds an optional two-packet
upload window, negotiated through the existing CONTROL characteristic. DATA
supports writes without response when both receiver and sender support them.
Older protocol-2 receivers and senders retain their existing transfer path.

Every packet reserves its slot until flash write/readback completes. Status
reports cumulative durable bytes; queue admission alone never advances progress.
Wrong-session, duplicate, missing, out-of-order and excess packets cannot be
mistaken for committed data. Reconnect discards the uncommitted queue and resumes
at the durable offset. VERIFY waits for all bytes and an empty queue.

Only the explicit OTA owner requests a 7.5–15 ms connection interval with zero
peripheral latency. Rejection is benign and other devices retain their link
parameters. Both senders now report transfer timing; Python Bluetooth operations
have bounded waits and complete cancellation before reconnecting.

## Validation

- Pinned NimBLE host ASan/UBSan tests cover actual ATT Write Commands, two-slot
  pressure, cumulative acknowledgements, spectator isolation, MTU-changing resume,
  and accepted/rejected connection-parameter requests. Existing two-device SC
  pairing, three-connection OTA, ANCS, cache migration and 100-cycle tests pass.
- Twelve port sanitizer suites, Go race tests and vet pass. Python and browser
  tests cover lost packets/notifications, queue pressure, invalid acknowledgements,
  receiver reset, readback failure and native-operation cancellation.
- Deterministic actual-sender benchmarks use the same 47,200-byte image and timing
  fixtures in Python and JavaScript. In the latency-bound fixture, data time is
  14.000 s with the old method and 7.008 s with two Write Commands outstanding.
  In the flash-bound fixture it is 41.000 s versus 40.005 s. These are simulations,
  not measured watch throughput. Run `python3 scripts/ota_benchmark.py` or
  `node scripts/ota_benchmark.mjs` to reproduce them.
- ARM image: 296,796 bytes. Reserved RAM: 24,180 bytes; heap region: 41,356 bytes;
  task stack: 8,192 bytes. The existing 40 KiB heap floor and stack reserve pass.
  The host allocation arena peaks at 3,056 of 5,120 bytes in the sanitizer harness.
  These are static budgets and host measurements, not physical free-heap readings.

## Hardware status and next work

The package is built and validated but has not been uploaded. The user deferred
further speed work and flashing to optimize memory first. A larger upload window
would consume additional RAM and remains future work. The first upload installing
this receiver still uses the installed firmware's transfer method; its physical
speed must be measured on a subsequent transfer. InfiniLink Home completion and
the prior candidate's boot/KEEP remain unconfirmed by the user.
