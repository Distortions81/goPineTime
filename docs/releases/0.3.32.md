# goPine 0.3.32 battery confirmations and dependency audit

Changing backlight brightness or enabling touch wake, Bluetooth, or notification
buzz now opens a battery-use explanation with Cancel and Confirm. The selected
setting stays unchanged until confirmation. Cancel, swipe-back, input cancellation,
or sleep discards the proposal. Turning off touch wake/Bluetooth or choosing Quiet
is immediate; pairing another device while Bluetooth is already enabled does not
repeat the explanation. Existing saved choices and notification defaults remain.

The copy explains active touch sensing and accidental screen wakes, the relative
cost of the three backlight levels, Bluetooth activity during sleep, and the
notification motor. Quiet explicitly retains message reception. It makes no
unmeasured percentage or runtime claim. Dark/Light theme and rotation stay direct
controls. One byte of existing UI padding holds the proposal: the ARM UI remains
712 bytes, and checkpoint settings/records remain unchanged.

## Linked dependency audit

The audit uses the actual ARM ELF and controlled builds with identical source,
version, and build date/time. Imported-package lists alone overstate retained
code because the linker removes unused functions.

| Change | Measured result | Decision |
| --- | --- | --- |
| Bounded Bluetooth UUID formatter instead of `sprintf` | 1,504 fewer flash bytes; formatter frame 112 → 24 bytes | Kept |
| Seven byte-order helpers vendored from Go 1.27.1 instead of `encoding/binary` | 8 fewer flash bytes; unchanged static RAM | Removed experiment; keep standard helpers |

`port/uuid.c` preserves the pinned NimBLE UUID operations and replaces only its
formatter. The existing upstream include/wrapper pattern avoids maintaining a
second copy of unrelated wire handling. The host harness compares all 65,536
16-bit values, 65,536 32-bit values, 65,536 128-bit values, and unknown types
against upstream, including surrounding buffer guards. Both the general C
formatter and the original UUID formatter are absent from the final ELF; the
resource gate now rejects their return.

The report also records remaining linked symbol groups:

| Group | Flash symbol bytes | Static RAM symbol bytes |
| --- | ---: | ---: |
| Time/calendar | 11,878 | 140 |
| Reflection and type metadata | 10,618 | 0 |
| Text and numeric helpers | 1,282 | 0 |
| General C formatters | 0 | 0 |

These are selected named symbols, not total package cost: inlined code belongs
to callers, aliases are counted once, and heap allocations are excluded. Time's
local-location initialization retains timezone loading and interface comparison;
TinyGo's panic formatting retains `time.Time.String`. Removing this safely would
require a narrower clock/runtime implementation or changed panic behavior, so
neither was changed merely to reduce size. Existing guards still reject Go `fmt`,
FIPS initialization, the standard CRC table, and general `Time.Format`.

The target dependency list excludes SDL, host packaging/ZIP/JSON, and the driver's
smoke-test `shlex` dependency. Their module entries remain for other build targets.
The stock Go all-tags tidy check cannot complete in this offline environment
(uncached `shlex` and TinyGo-only imports); the actual desktop and TinyGo target
builds are the validation used here.

## Validation and package

Go tests/race/vet, 20 resource-checker tests, native NimBLE ASan/UBSan integration,
the ARM resource gate, package validation, and inspected SDL confirmation previews
pass. Tests cover deferred changes, all cancellation paths, overlay priority,
notification muting, Bluetooth setup timing, saved settings, text width, zero
steady-state drawing allocations, and both themes' strip/full-frame equivalence.

The image is 296,260 bytes. Reserved RAM remains 22,132 bytes, with a 43,404-byte
heap region. The largest selected stack path plus its 2,048-byte reserve is
7,968 of 8,192 bytes. These are regression budgets, not physical free-heap or
whole-program stack measurements. Includes the exclusive OTA and recycling
changes from [0.3.31](0.3.31.md).
